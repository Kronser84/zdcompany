## Особенность резервной копии

Содержимое четырёх файлов сохранено из точной revision 3.3; **две ссылки на изображение MagicPath** заменены на локальный путь `/assets/hero-magicpath-revision2.jpg`, чтобы оформление не зависело от доступности MagicPath CDN. Это единственное намеренное изменение исходников относительно извлечённой ревизии.

Для восстановления компонента требуется React/TypeScript-среда и поддержка CSS/Tailwind согласно требованиям исходного макета. Скрипты сборки и зависимости этого макета в текущий комплект не включены; производственный сайт остаётся статическим HTML/CSS. В `src/index.css` остаётся внешняя ссылка на Google Fonts с предусмотренными системными fallback-шрифтами.
