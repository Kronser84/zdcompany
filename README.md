# ЖДК — корпоративный сайт zdcompany.ru

Репозиторий корпоративного сайта ООО «ЖДК». Для нового дизайнера и разработчика **начальная точка — этот README**.

## Дизайн и концепция

1. **[Дизайн-система ЖДК](docs/DESIGN-SYSTEM.md)** — общие правила оформления продуктов компании: типографика, цвет, композиция, графика, адаптивность.
2. **[Визуально-текстовая концепция сайта](docs/SITE-CONCEPT.md)** — замысел и структура именно этого сайта, утверждённые решения, история редакций, открытые изменения и критерии проверки.
3. **[Последний редактируемый макет: MagicPath, редакция 3.2](https://www.magicpath.ai/files/471924879986401280)** — компонент `471956122253811712`, последняя проверенная ревизия `471957744535109632`. Предыдущие редакции 3 и 3.1 находятся рядом в том же проекте.
4. **[Описание статической реализации редакции 3.2](design/source-v3.2.md)** — как подготовлены текущие HTML/CSS и изображения; документ описывает более раннюю ревизию макета, поэтому для новой реализации сверяйте актуальную концепцию.
5. **[Контракт SKYNET №405](https://github.com/Kronser84/KB-SKYNET/issues/405)** — управление задачами, решения Owner и маршрут исполнения.

**Порядок работы:** открыть дизайн-систему → концепцию → выбранную ревизию MagicPath → сопоставить с текущим кодом. **Не считать макет автоматически опубликованным или синхронизированным с репозиторием.**

## Исходники сайта

- `index.html` — главная;
- `about.html` — о компании;
- `contacts.html` — контакты;
- `style.css` — стили;
- `assets/` — локальные изображения.

Содержание, реквизиты и наименование компании перед публикацией следует сверять с актуальными документами. Последнее поручение Owner об удалении юридического адреса и подписей в контактных окнах зафиксировано в концепции как **ещё не внесённое в редактируемый макет**.
